# 你好法语 · cahier de dictée

《你好法语 1》逐课练习：词汇默写、句子（填空 / 中译法 / 听写）、全文默写、语音背诵，带朗读和错题本（隔天复习）。

在线使用：https://sunyux.github.io/dictation/

数据由 `tools/build_data.py` 从默写讲义 PDF 的文字生成 `data.js`。

## NLF · Road to A1 / A2 / B1-B2 (vocabulary books)

Three word-only books built from the NLF Google Sheets (`nlf-data.js`, `nlf-a2.js`, `nlf-b.js`, generated by `tools/build_nlf.py <a1|a2|b>`).
Sheet rows live in `tools/nlf/*.json`; the Chinese meanings, example translations and memory tips are in `tools/nlf/*_uN.txt`
(`idx|中文|pos|例句中文|提示中文|tip English`). Each unit has Browse / Study first / First test / Dictation, and the sheet's example
sentences feed the Sentences tab (fill the gaps, translate, dictation).
